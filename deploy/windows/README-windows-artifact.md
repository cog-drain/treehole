# Treehole Windows Artifact Deployment

This package is generated by GitHub Actions for a Windows native runtime.

## Contents

```text
treehole-windows/
  backend/
    treehole-backend.jar
  frontend/
    index.html
    assets/
  deploy/
    nginx-treehole.conf
  scripts/
    start-backend.ps1
  database/
    01_init.sql
    02_test_data.sql
  .env.windows.example
  README-windows-artifact.md
```

## Runtime Requirements

- JDK 17
- MySQL 8.0+ or MariaDB 11.0+
- Redis-compatible service listening on the configured host and port
- Windows Nginx

Node.js is not required at runtime. The frontend files in `frontend/` are already built static assets.

## Install Layout

Extract the package so the final layout is:

```text
C:\treehole\
  backend\
    treehole-backend.jar
  frontend\
    index.html
    assets\
  deploy\
    nginx-treehole.conf
  scripts\
    start-backend.ps1
  database\
    01_init.sql
    02_test_data.sql
  storage\
    uploads\
    logs\
  .env
```

Create storage directories if they do not exist:

```powershell
mkdir C:\treehole\storage\uploads
mkdir C:\treehole\storage\logs
```

Copy the environment template and replace all placeholders:

```powershell
copy C:\treehole\.env.windows.example C:\treehole\.env
notepad C:\treehole\.env
```

Use forward slashes in Java path environment variables:

```env
UPLOAD_PATH=C:/treehole/storage/uploads
LOG_PATH=C:/treehole/storage/logs
```

## Database

Create the database and application user in MySQL or MariaDB first, then initialize the schema:

```powershell
mysql -u treehole_user -p treehole < C:\treehole\database\01_init.sql
```

Optional demo data:

```powershell
mysql -u treehole_user -p treehole < C:\treehole\database\02_test_data.sql
```

## Backend

Start MySQL/MariaDB and Redis-compatible service before starting the backend:

```powershell
powershell -ExecutionPolicy Bypass -File C:\treehole\scripts\start-backend.ps1 `
  -EnvFile C:\treehole\.env `
  -JarPath C:\treehole\backend\treehole-backend.jar
```

Check the backend:

```powershell
curl http://127.0.0.1:24191/api/messages
```

## Nginx

Copy or include `C:\treehole\deploy\nginx-treehole.conf` in your Windows Nginx configuration.

The default config assumes:

- Static frontend root: `C:/treehole/frontend`
- Backend origin: `http://127.0.0.1:24191`
- Public HTTP port: `80`

Reload Nginx and visit:

```text
http://localhost
```

For LAN access, open port `80` in Windows Firewall and use the Windows device IP address.
