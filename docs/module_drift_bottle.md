# 模块开发文档 - 虚灵之海 (Drift Bottle)

## 1. 模块概述
本模块实现了匿名社交中的“异步时空”交互。用户可以将一段文字放入瓶中投入大海（全局池），系统会自动为瓶子分配随机的主题和漂流路径。其他用户可以在海面上随机捞起这些瓶子。

## 2. 核心功能与 CRUD 实现
- **C (Throw)**：用户发布瓶子，初始化 `state=0` (漂流中)。
- **R (Pick)**：后端通过 `SELECT ... WHERE state=0 ORDER BY RAND() LIMIT 1` 实现随机捞取。
- **U (Reply/Return)**：
  - **回复**：捞起者填充 `reply_content`，更新 `state=1` (被捞起)。
  - **退回**：捞起者不回复直接放回，更新 `state=2` 或重置为 `0`。
- **D (Delete)**：瓶子所有者可以撤回自己的瓶子，执行物理删除或逻辑删除。

## 3. 技术难点：状态机与并发
漂流瓶的“捞取”动作涉及并发冲突（两个用户同时捞到一个瓶子）。
- **解决方案**：在持久层使用 MyBatis-Plus 的 `Optimistic Locking` (乐观锁) 或者通过 `UPDATE ... WHERE id = ? AND state = 0` 进行原子更新，确保瓶子只会被一个用户成功锁定。

## 4. 前端交互设计
- 使用 Vue 3 的动画钩子实现瓶子“浮动”特效。
- 集成 **回响中心**：当瓶子被他人捞起时，通过 WebSocket 发送即时通知给原作者，引导其打开“回响中心”查看回复。
