# 模块开发文档 - 匿名留言广场 (Message Square)

## 1. 模块概述
匿名留言是整个项目的流量核心。它提供了一个公开的、支持无限流滚动的广场，展示所有用户发布的心声。

## 2. 核心功能
- **内容发布**：支持文本、心情标签（Mood）以及主题模板的选定。
- **互动体系**：
  - **点赞 (Likes)**：基于 IP 或 UUID 的防重复点赞。
  - **共鸣回复 (Reactions)**：支持 JSON 格式的多类型表情统计。
- **分页加载**：通过 MyBatis-Plus 的 `Page` 分页插件实现高效的数据查询。

## 3. 设计亮点：去中心化 ID
本模块不使用自增 ID 作为对外展示的标识（虽然数据库底层有自增 ID），而是统一通过随机生成的 UUID (`user_id`) 进行逻辑管理，确保了匿名性的物理隔离。

## 4. 异常处理机制
- **关键字过滤**：后端集成敏感词检测。
- **频率限制**：针对同一个 IP 地址，设置了每分钟发布留言的上限，防止脚本恶意刷屏。
