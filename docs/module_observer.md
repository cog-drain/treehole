# 模块开发文档 - AI 守望者与 Alter Ego

## 1. 模块概述
本项目深度集成了 AI 赋能的情感交互。通过 `AIService` 对接智谱 AI (GLM-4)，实现了两个维度的 AI 参与：
- **Observer (静默守望者)**：后台定期扫描热门留言并生成感悟。
- **Alter Ego (互动人格)**：一个可拖拽的黑客风格终端，为用户提供实时、带有强人设（弹丸论破风格）的希望注入对话。

## 2. 技术栈
- **后端**：使用 Spring `RestTemplate` 封装 OpenAI 协议调用。
- **提示词工程 (Prompt Engineering)**：
  - 设计了复杂的状态化提示词，要求 AI 严格遵守 `[DATA ANALYSIS] ... [HOPE INJECTION]` 的输出格式。
  - 角色设定（Persona）：谦逊、热诚、严谨的 AI 助手。

## 3. 设计挑战：稳定性与性能
- **问题**：AI 响应通常较慢（2-5秒），会阻塞用户操作。
- **对策**：
  - 前端采用异步非阻塞调用，对话框展示“正在分析数据...”的 Loading 状态。
  - 后端增加了异常处理逻辑，在 API 熔断时返回预设的“温暖错误消息”，保证用户体验不中断。

## 4. 视觉呈现
- **Alter Ego 终端**：完全由 CSS 构建的模拟终端 UI，包括扫描线效果、绿色单色调背景和矩阵点阵动画。
- **动态进度条**：基于留言字数和情感关键词计算出的“希望指数”可视化呈现。
